# Privacy Labels & Data Safety Answers

两个商店都要求填写数据收集声明。本 App 是纯本地存储，**不收集、不传输、不共享
任何数据**，因此两平台都按「不收集数据」填写。

## Google Play — 数据安全表单（Data safety form）

| 问题 | 答案 |
|---|---|
| 是否收集或共享任何数据类型？ | **否**（全部勾选 No data collected） |
| 数据是否加密传输？ | 不适用（无数据传输） |
| 用户能否要求删除数据？ | 是——卸载 App 即删除本机全部数据 |

说明文字（可附在表单里）：

> Vaultell is a local-first app. All data entered by the user is stored only
> on the user's device. The app does not collect, transmit or share any personal data,
> and does not include advertising, analytics or tracking SDKs.

注意：用户主动使用「导出备份」分享文件、或打开保险公司理赔页面，属于用户主动操作，
不属于 App 收集数据。

## Apple App Store — 隐私标签（Privacy Nutrition Labels）

选择 **Data Not Collected**（不收集数据）。

说明：App 内的保单信息、文件、提取结果均只存储在用户设备本地，不离开设备；
App 无账号系统、无分析、无广告、无第三方 SDK 收集数据。

如果 Apple 审核时要求细化「User Content」等分类，按以下口径回答：

| 分类 | 答案 |
|---|---|
| User Content（用户内容） | 存储在设备本地，不收集/不上传 |
| Contact Info（联系方式） | 不收集 |
| Identifiers（标识符） | 不收集 |
| Diagnostics（诊断数据） | 不收集 |
| 其他所有类别 | 不收集 |

> 注意：只有真正添加云端功能（AI 提取、加密备份）时，才需要改为逐项披露，
> 并同步更新 [PRIVACY_POLICY.md](PRIVACY_POLICY.md)。
